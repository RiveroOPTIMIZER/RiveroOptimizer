# Rivero Optimizer

Optimizador de Windows con identidad visual negra y verde, interfaz en español y enfoque en cambios explicados, seguros y reversibles.

## Estructura del proyecto

- **Rivero Optimizer:** interfaz principal inspirada en la organización de WinUtil de Chris Titus Tech.
- **Sophia Script:** sección independiente para una integración separada de Sophia Script for Windows.
- **Información:** datos del proyecto y contacto.

## Estado

La interfaz actual es una versión de desarrollo. La pestaña Sophia Script es informativa y todavía no ejecuta sus funciones. Algunas opciones de la interfaz principal también permanecen deshabilitadas hasta que tengan una implementación y una ruta de reversión verificadas.

No se desactivan de forma automática Microsoft Defender, Firewall, UAC, BitLocker, Secure Boot ni Windows Update. Las funciones que modifiquen Windows deben explicar el cambio y conservar una forma segura de restaurarlo.

**No consideres esta versión una compilación final ni ejecutes ajustes que no estén documentados y probados en Windows.**

## Reglas
- Mantener la estructura y distribución funcional de WinUtil.
- No rediseñar la aplicación desde cero.
- Traducir textos visibles al español sin cambiar identificadores internos que usa el código.
- Usar verde para selección, acciones primarias y estados; no convertir toda la interfaz en verde.
- Mantener contraste legible.
- Selector PC / LAPTOP visible y con selección manual; la detección automática será solo una sugerencia.
